# Sunrise Dental Clinic Appointment and Patient Management System

## Project Overview

The Sunrise Dental Clinic Appointment and Patient Management System is a Java-based distributed application proposed to improve the management of patient appointments and related clinic activities.

The system will provide staff authentication, appointment registration, appointment searching, billing, and help functionality.

## Proposed Technologies

- Java
- HTML5
- CSS3
- JavaScript
- Bootstrap
- PostgreSQL
- JDBC
- Maven
- JUnit
- Postman
- Git and GitHub
