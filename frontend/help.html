Sunrise Dental Clinic

Appointment & Patient Management System

Help & User Guide

Follow the instructions below to use the Sunrise Dental Clinic system.

1. Login to the System

  1. Open the Sunrise Dental Clinic login page.
  2. Enter your authorized username.
  3. Enter your password.
  4. Click the Login button.
  5. If the credentials are correct, the dashboard will be displayed.

2. Register a New Appointment

  1. Open Register Appointment from the dashboard.
  2. Enter a unique appointment number.
  3. Select the patient.
  4. Select the dentist.
  5. Select the required treatment.
  6. Choose the appointment date and time.
  7. Enter any additional notes if required.
  8. Click Register Appointment.
  9. A successful registration message will be displayed.

3. Search for an Appointment

  1. Open Search Appointment.
  2. Enter the appointment number.
  3. Click Search Appointment.
  4. The system displays the appointment, patient, dentist and treatment details.

4. Calculate a Patient Bill

  1. Open Billing from the dashboard.
  2. Enter the appointment number.
  3. Click Calculate Bill.
  4. The system retrieves the appointment information.
  5. The treatment cost and consultation fee are calculated by the system.
  6. The total amount is displayed.

5. Print a Bill / Receipt

  1. Generate the bill using the Billing page.
  2. Review the displayed bill information.
  3. Click Print Bill / Receipt.
  4. Use the browser print dialog to print or save the receipt.

6. Logout

  1. Click the Logout button.
  2. The system returns to the login page.

7. Common Messages

  • Invalid username or password: Check the login credentials.
  • Unable to register appointment: Check that the appointment number is unique and all required information is valid.
  • Appointment not found: Check the appointment number and search again.
  • Bill not found: Generate the bill for the appointment before retrieving the bill.
  • Unable to connect to the server: Check that the Java Spring Boot backend is running on port 8080.
